# Resume Parser

Resume Parser is a project focused on developing and integrating computer vision and natural language processing techniques for automated resume analysis. It extracts and structures key candidate information from diverse resume formats by combining document layout analysis, optical character recognition, and contextual language understanding into a unified processing pipeline.


## Quickstart


To start with the project and install its dependencies, it uses the [uv package manager](https://docs.astral.sh/uv/getting-started/installation/). Clone the repository and navigate to the project root directory.

1. Install Required packages

    To create a new python virtual environment, run the given command:

    ```bash
    uv venv --python <your-python-version>
    ```

    To use existing environment (if already created), run the following command:

    ```bash
    source <path-to-.venv>/bin/activate
    ```

    Make sure you are on the project root directory and then run the following command to install all the required packages to run the program smoothly:

    ```bash
    uv sync
    ```

For further instruction visit the [docs](./docs) directory within the project repo itself.
